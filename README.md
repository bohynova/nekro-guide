# Некровирус — памятка за столом

Русская шпаргалка по Twilight Imperium IV с Prophecy of Kings, Thunder’s Edge и материалами Codex. Подготовлена для стола из шести фракций: Некровирус, Винну, Титаны Ула, Консорциум Рал Нел, Последний бастион и Альянс Нааз-Рокха.

## Устройство сайта

Сайт статический: сборка, установка зависимостей и сервер не нужны.

- `index.html` — оболочка сайта.
- `style.css` — оформление.
- `content.js` — материалы и официальные источники FFG.
- `app.js` — вкладки и навигация.
- `assets/table-map.png` — карта партии, предоставленная автором запроса.
- `.nojekyll` — отключает обработку сайта через Jekyll.

Ссылки на экраны используют фрагменты, например `#rules/combat`. Пути к стилям, скриптам и карте относительные, поэтому сайт работает как в корне домена, так и по адресу проекта GitHub Pages.

## GitHub Pages

В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main** и папку **/ (root)**. Нажмите **Save**. После успешной публикации GitHub покажет адрес сайта.

Чтобы обновить сайт, измените файлы в ветке `main`. GitHub Pages опубликует обновления автоматически.

Для проверки локально можно открыть `index.html` в браузере или запустить `python3 -m http.server 8000` в папке сайта.

## Источники и ограничения

Правила сопровождаются ссылками на официальные материалы Fantasy Flight Games в разделе «Источники». Советы по стратегии — авторские выводы для указанного состава игроков.

Основной вариант памятки — игра до 10 очков. Опциональные события и вариант до 14 очков нужно подтвердить за столом. Полный текст Valefar Assimilator Z не найден в проверенных официальных PDF; памятка отмечает необходимость сверки с физическим компонентом.

Twilight Imperium и названия игровых компонентов принадлежат их правообладателям. Это неофициальная памятка.
